    2. Perceptron — Separabilidade: quando converge e como falha¶

    Como reproduzir

    python3 -m pip install -r requirements.txt
python3 docs/exercises/perceptron/code/main.py

    main.py cria um único gerador rng = np.random.default_rng(42) e o usa, nessa ordem, para os dados do Exercício 1, o \(\mathbf{w}\) inicial do Exercício 1, os dados do Exercício 2 e o \(\mathbf{w}\) inicial do Exercício 2. As execuções extras (outro \(\eta\), partida do zero, mais épocas) reaproveitam esses mesmos pesos iniciais.     Código — perceptron.py (o modelo usado nos dois exercícios) 
    """Perceptron de uma camada, escrito do zero em NumPy (Exercícios 1 e 2).

Rótulos em {0, 1}. Predição: y_hat = step(w·x + b), com step(z) = 1 se z >= 0.
Regra de atualização (amostra a amostra):
    w <- w + eta (y - y_hat) x,     b <- b + eta (y - y_hat)
O erro (y - y_hat) vale 0 num acerto (não atualiza) e +1/-1 nos dois tipos de erro.

A mesma classe serve aos dois exercícios, sem nenhuma alteração. Ela também guarda o
"bolso" (pocket): a melhor (w, b) já vista na base inteira. No Exercício 1 o bolso só
acompanha a convergência; no Exercício 2 é ele que importa.
"""
import numpy as np


def step(z):
    """Função degrau: 1 se z >= 0, 0 caso contrário."""
    return (np.asarray(z) >= 0).astype(int)


class Perceptron:
    def __init__(self, w_init, eta, b_init=0.0):
        """w_init vem de fora (rng.normal(0, 0.01, size=2)) para que duas execuções possam
        partir exatamente do mesmo ponto e diferir só em eta (Exercício 1D)."""
        self.w = np.array(w_init, dtype=float)  # cópia: não altera o vetor de quem chamou
        self.b = float(b_init)
        self.eta = float(eta)

    def net_input(self, X):
        return X @ self.w + self.b

    def predict(self, X):
        return step(self.net_input(X))

    def accuracy(self, X, y):
        return float(np.mean(self.predict(X) == y))

    def fit(self, X, y, max_epochs=100):
        """Treina na ordem das linhas de X até uma época sem nenhuma atualização ou max_epochs.

        Devolve um histórico com, por época: acurácia na base inteira ao fim da época,
        nº de atualizações e acurácia do bolso; e, por atualização: posição (em épocas),
        acurácia logo após ela e os pesos (w, b) logo após ela.
        """
        n = len(y)
        best_acc = self.accuracy(X, y)          # o bolso começa com os pesos iniciais
        pocket = {"w": self.w.copy(), "b": self.b, "accuracy": best_acc, "epoch": 0}
        self.initial_accuracy = best_acc
        hist = {"accuracy": [], "updates": [], "pocket_accuracy": [],
                "update_position": [], "update_accuracy": [], "update_w": [], "update_b": []}
        converged = False

        for epoch in range(1, max_epochs + 1):
            n_updates = 0
            for i in range(n):
                y_hat = step(self.w @ X[i] + self.b)
                error = y[i] - y_hat                  # 0, +1 ou -1
                if error != 0:
                    self.w += self.eta * error * X[i]
                    self.b += self.eta * error
                    n_updates += 1
                    # bolso: a única coisa a mais no laço. Só uma atualização muda a acurácia.
                    acc = self.accuracy(X, y)
                    hist["update_position"].append(epoch - 1 + (i + 1) / n)
                    hist["update_accuracy"].append(acc)
                    hist["update_w"].append(self.w.copy())
                    hist["update_b"].append(self.b)
                    if acc > best_acc:
                        best_acc = acc
                        pocket = {"w": self.w.copy(), "b": self.b, "accuracy": acc, "epoch": epoch}
            hist["accuracy"].append(self.accuracy(X, y))
            hist["updates"].append(n_updates)
            hist["pocket_accuracy"].append(best_acc)
            if n_updates == 0:                        # uma passada inteira sem erro: parou
                converged = True
                break

        self.pocket = pocket
        self.epochs = epoch
        self.converged = converged
        return {k: np.array(v) for k, v in hist.items()}

def to_builtin(obj):
    """Converte tipos do NumPy em tipos nativos para o JSON."""
    if isinstance(obj, dict):
        return {str(k): to_builtin(v) for k, v in obj.items()}

    Abordagem e desafios¶

    Abordagem. Uma única classe Perceptron serve aos dois exercícios, sem nenhuma alteração. O fit percorre as amostras uma a uma, calcula \(\hat y = \text{step}(\mathbf{w}\cdot\mathbf{x} + b)\) e aplica \(\mathbf{w} \leftarrow \mathbf{w} + \eta(y - \hat y)\mathbf{x}\), \(b \leftarrow b + \eta(y - \hat y)\). O laço para numa época sem nenhuma atualização ou em 100 épocas. Ao fim de cada época, mede a acurácia na base inteira. O bolso (pocket) também fica dentro do fit: depois de cada atualização, mede a acurácia na base inteira e guarda \((\mathbf{w}, b)\) se ela for a melhor até então. No Exercício 1 isso só acompanha a convergência; no Exercício 2 é a resposta.

    Desafios.

    • Ordem das amostras. A geração produz 1000 pontos da classe 0 seguidos de 1000 da classe 1. Embaralhei essa ordem uma vez, com o rng, e a mantive fixa em todas as épocas e execuções. Assim, no item 1D, a execução com \(\eta = 1.0\) difere da principal só em \(\eta\): mesmos dados, mesmo \(\mathbf{w}\) inicial, mesma ordem.
    • O resultado final do Exercício 2 depende de onde a época termina. O enunciado antecipa acurácia perto de 50% para os pesos finais. Com a ordem embaralhada obtive 64.85%; apresentando as classes em bloco, como saem da geração, obtive 50.25%. As duas coisas são a mesma oscilação vista em momentos diferentes. O item 2D explica e mostra as duas.
    • Custo do bolso. Avaliar a base inteira depois de cada uma das 76 620 atualizações do Exercício 2 é o passo mais caro do treino, mas leva cerca de 1 s.

    Exercício 1¶

    Dados separáveis: o caso para o qual o perceptron foi feito.

    Código completo — ex1_separable.py 
    """Exercício 1 — Dados separáveis: o caso para o qual o perceptron foi feito."""
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np

from perceptron import Perceptron

FIG_DIR = Path(__file__).resolve().parent.parent / "figures"

N_PER_CLASS = 1000
MEAN_0, MEAN_1 = np.array([1.5, 1.5]), np.array([5.0, 5.0])
COV = np.array([[0.5, 0.0], [0.0, 0.5]])
ETA = 0.01
ETA_ALT = 1.0
MAX_EPOCHS = 100

COLORS = ("tab:blue", "tab:red")
CLASS_NAMES = ("Classe 0", "Classe 1")


def make_data(rng, mean_0, mean_1, cov, n=N_PER_CLASS):
    """Duas gaussianas 2D, n pontos cada, embaralhadas UMA vez.

    Sem embaralhar, cada época veria 1000 pontos da classe 0 e depois 1000 da classe 1.
    A ordem embaralhada é sorteada aqui, uma vez só, e fica fixa em todas as épocas
    e em todas as execuções, para que só eta mude entre elas (item D).
    """
    X0 = rng.multivariate_normal(mean_0, cov, size=n)
    X1 = rng.multivariate_normal(mean_1, cov, size=n)
    X = np.vstack([X0, X1])
    y = np.repeat([0, 1], n)
    order = rng.permutation(len(y))
    return X[order], y[order]


def boundary_line(w, b, x1):
    """x2 da reta w1 x1 + w2 x2 + b = 0."""
    return -(w[0] * x1 + b) / w[1]


def unit(w):
    return w / np.linalg.norm(w)


def angle_deg(u, v):
    return float(np.degrees(np.arccos(np.clip(unit(u) @ unit(v), -1, 1))))


def novikoff_bound(X, y, n_angles=7200):
    """Limite de erros do teorema de convergência (Novikoff), com o viés embutido em (x, 1).

    Acha, por varredura de direções u, a reta de MAIOR margem geométrica gamma (metade do vão
    entre as projeções das duas classes) e o viés b* dessa reta. Com ||x|| <= R, o teorema
    garante no máximo (R^2 + 1)(1 + b*^2) / gamma^2 erros a partir de w = 0, b = 0.
    """
    best = (-np.inf, None, None)
    for theta in np.linspace(0, 2 * np.pi, n_angles, endpoint=False):
        u = np.array([np.cos(theta), np.sin(theta)])
        s = X @ u
        gap = s[y == 1].min() - s[y == 0].max()
        if gap > best[0]:
            best = (gap, theta, -(s[y == 1].min() + s[y == 0].max()) / 2)
    gap, theta, b_star = best
    gamma = gap / 2
    R = float(np.max(np.linalg.norm(X, axis=1)))
    return {"gamma": float(gamma), "b_star": float(b_star), "R": R,
            "direction": [float(np.cos(theta)), float(np.sin(theta))],
            "mistake_bound": float((R ** 2 + 1) * (1 + b_star ** 2) / gamma ** 2)}


def fig1_scatter(X, y, title, path, means):
    fig, ax = plt.subplots(figsize=(6.5, 6))
    for k in (0, 1):
        ax.scatter(X[y == k, 0], X[y == k, 1], s=8, alpha=0.5, c=COLORS[k],
                   label=f"{CLASS_NAMES[k]} (n = {np.sum(y == k)}, média {tuple(means[k])})")
    ax.set_title(title)
    ax.set_xlabel("$x_1$")
    ax.set_ylabel("$x_2$")
    ax.set_aspect("equal")
    ax.legend(loc="upper left", fontsize=9)
    ax.grid(alpha=0.3)
    fig.tight_layout()
    fig.savefig(path, dpi=150)
    plt.close(fig)


def fig2_boundary(X, y, model):
    fig, ax = plt.subplots(figsize=(6.5, 6))
    pred = model.predict(X)
    for k in (0, 1):
        m = (y == k) & (pred == y)
        ax.scatter(X[m, 0], X[m, 1], s=8, alpha=0.5, c=COLORS[k], label=f"{CLASS_NAMES[k]} (acerto)")
    wrong = pred != y
    ax.scatter(X[wrong, 0], X[wrong, 1], s=60, marker="x", c="k", label=f"classificado errado ({wrong.sum()})")
    x1 = np.linspace(X[:, 0].min() - 0.5, X[:, 0].max() + 0.5, 2)
    ax.plot(x1, boundary_line(model.w, model.b, x1), c="k", lw=2,
            label=r"fronteira $\mathbf{w}\cdot\mathbf{x} + b = 0$ ($\eta = 0.01$)")
    ax.set_xlim(X[:, 0].min() - 0.5, X[:, 0].max() + 0.5)
    ax.set_ylim(X[:, 1].min() - 0.5, X[:, 1].max() + 0.5)
    ax.set_title("Figura 2 — Fronteira de decisão aprendida (Exercício 1)")
    ax.set_xlabel("$x_1$")
    ax.set_ylabel("$x_2$")
    ax.set_aspect("equal")
    ax.legend(loc="upper left", fontsize=9)
    ax.grid(alpha=0.3)
    fig.tight_layout()
    fig.savefig(FIG_DIR / "fig2_boundary.png", dpi=150)
    plt.close(fig)


def fig3_accuracy(runs):
    """(a) acurácia x época; (b) acurácia logo após cada atualização, dentro da época 1."""
    fig, (a, b) = plt.subplots(1, 2, figsize=(12, 4.4))
    styles = {ETA: ("tab:purple", "o", "-"), ETA_ALT: ("tab:orange", "s", "--")}
    for eta, (model, hist) in runs.items():
        c, mk, ls = styles[eta]
        acc = np.concatenate([[model.initial_accuracy], hist["accuracy"]]) * 100
        a.plot(np.arange(len(acc)), acc, c=c, marker=mk, ls=ls, label=rf"$\eta = {eta}$")
        pos = np.concatenate([[0], hist["update_position"]])
        ua = np.concatenate([[model.initial_accuracy], hist["update_accuracy"]]) * 100
        b.step(pos, ua, where="post", c=c, ls=ls, label=rf"$\eta = {eta}$ ({len(hist['update_accuracy'])} atualizações)")
    a.set_xticks(range(0, 3))
    a.set_xlabel("Época (0 = pesos iniciais)")
    a.set_ylabel("Acurácia na base inteira (%)")
    a.set_title("(a) Acurácia ao fim de cada época")
    b.set_xlabel("Posição na época 1 (fração das 2000 amostras)")
    b.set_ylabel("Acurácia na base inteira (%)")
    b.set_title("(b) Acurácia logo após cada atualização")
    b.set_xlim(0, 1)
    for ax in (a, b):
        ax.grid(alpha=0.3)
        ax.legend(loc="lower right")
    fig.suptitle("Figura 3 — Acurácia × época (Exercício 1)")
    fig.tight_layout()
    fig.savefig(FIG_DIR / "fig3_accuracy.png", dpi=150)
    plt.close(fig)


def fig_c1_eta(X, y, models):
    """Complementar: as fronteiras de eta = 0.01, eta = 1.0 e da partida do zero, na região do vão."""
    fig, ax = plt.subplots(figsize=(6.5, 6))
    for k in (0, 1):
        ax.scatter(X[y == k, 0], X[y == k, 1], s=10, alpha=0.5, c=COLORS[k], label=CLASS_NAMES[k])
    x1 = np.linspace(0, 6.5, 2)
    for (label, model), (c, ls) in zip(models.items(), (("k", "-"), ("tab:orange", "--"), ("tab:green", ":"))):
        ax.plot(x1, boundary_line(model.w, model.b, x1), c=c, ls=ls, lw=2, label=label)
    ax.set_xlim(1.0, 5.5)
    ax.set_ylim(1.0, 5.5)
    ax.set_title("Figura C1 (complementar) — Fronteiras por $\\eta$ e partida")
    ax.set_xlabel("$x_1$")
    ax.set_ylabel("$x_2$")
    ax.set_aspect("equal")
    ax.legend(loc="upper left", fontsize=8.5)
    ax.grid(alpha=0.3)
    fig.tight_layout()
    fig.savefig(FIG_DIR / "fig_c1_eta.png", dpi=150)
    plt.close(fig)


def summarize(model, hist):
    return {
        "w": model.w.tolist(), "b": model.b,
        "direction": unit(model.w).tolist(), "norm_w": float(np.linalg.norm(model.w)),
        "distance_origin_to_boundary": float(abs(model.b) / np.linalg.norm(model.w)),
        "epochs": model.epochs, "converged": model.converged,
        "updates_per_epoch": hist["updates"].tolist(),
        "total_updates": int(hist["updates"].sum()),
        "initial_accuracy": model.initial_accuracy,
        "accuracy_per_epoch": hist["accuracy"].tolist(),
        "final_accuracy": float(hist["accuracy"][-1]),
        "last_update_position_epoch1": float(hist["update_position"][-1]) if len(hist["update_position"]) else None,
    }


def run(rng):
    FIG_DIR.mkdir(exist_ok=True)

    # A — dados
    X, y = make_data(rng, MEAN_0, MEAN_1, COV)
    fig1_scatter(X, y, "Figura 1 — Dados separáveis (Exercício 1)", FIG_DIR / "fig1_data.png",
                 (MEAN_0.tolist(), MEAN_1.tolist()))

    # B/C — perceptron com eta = 0.01 a partir de w ~ N(0, 0.01^2), b = 0
    w0 = rng.normal(0, 0.01, size=2)
    model = Perceptron(w0, ETA)
    hist = model.fit(X, y, max_epochs=MAX_EPOCHS)
    fig2_boundary(X, y, model)

    # D — mesma partida (w0, b = 0) e mesma ordem; só eta muda
    model_alt = Perceptron(w0, ETA_ALT)
    hist_alt = model_alt.fit(X, y, max_epochs=MAX_EPOCHS)
    fig3_accuracy({ETA: (model, hist), ETA_ALT: (model_alt, hist_alt)})

    # D — conferência numérica da partida do zero (a prova algébrica está no relatório)
    zero = {}
    for eta in (ETA, ETA_ALT):
        m = Perceptron(np.zeros(2), eta)
        h = m.fit(X, y, max_epochs=MAX_EPOCHS)
        zero[eta] = (m, h)
    (mz1, hz1), (mz2, hz2) = zero[ETA], zero[ETA_ALT]
    ratio_w = (mz2.w / mz1.w).tolist()
    ratio_b = mz2.b / mz1.b
    fig_c1_eta(X, y, {r"$\eta = 0.01$, partida $\mathbf{w}_0$": model,
                      r"$\eta = 1.0$, partida $\mathbf{w}_0$": model_alt,
                      r"partida $\mathbf{w} = \mathbf{0}$ (qualquer $\eta$)": mz1})

    s, s_alt = summarize(model, hist), summarize(model_alt, hist_alt)
    print(f"[Ex1] eta=0.01: {model.epochs} épocas, {s['total_updates']} atualizações, acc {s['final_accuracy']:.4f} | "
          f"eta=1.0: {model_alt.epochs} épocas, {s_alt['total_updates']} atualizações | "
          f"ângulo entre w: {angle_deg(model.w, model_alt.w):.2f}° | zero: razão w {ratio_w}, b {ratio_b:.4f}")
    return {
        "class_means_sample": [X[y == k].mean(axis=0).tolist() for k in (0, 1)],
        "w0": w0.tolist(), "w0_over_eta": (w0 / ETA).tolist(),
        "eta_0.01": s,
        "eta_1.0": s_alt,
        "angle_between_directions_deg": angle_deg(model.w, model_alt.w),
        "zero_start": {
            "eta_0.01": summarize(mz1, hz1), "eta_1.0": summarize(mz2, hz2),
            "w_ratio": ratio_w, "b_ratio": ratio_b,
            "same_predictions": bool(np.array_equal(mz1.predict(X), mz2.predict(X))),
            "angle_to_eta1_run_deg": angle_deg(mz1.w, model_alt.w),
        },
        "novikoff": novikoff_bound(X, y),
        "mean_norm_x": float(np.linalg.norm(X, axis=1).mean()),
    }

    A — Gere os dados¶

    make_data(rng, ...) sorteia 1000 pontos por classe com rng.multivariate_normal: classe 0 com média \((1.5, 1.5)\) e classe 1 com média \((5, 5)\), as duas com covariância \(\begin{bmatrix} 0.5 & 0 \\ 0 & 0.5 \end{bmatrix}\). As médias amostrais ficaram em \((1.450,\ 1.473)\) e \((5.010,\ 5.013)\). A distância entre as médias (\(\approx 4.95\)) é cerca de 7 desvios-padrão (\(\sqrt{0.5} \approx 0.71\)).

    B — Implemente o perceptron¶

    A implementação está em perceptron.py (código acima):

    • Predição: step(z) devolve 1 se \(z \ge 0\) e 0 caso contrário, e \(\hat y = \text{step}(\mathbf{w}\cdot\mathbf{x} + b)\).
    • Atualização: com rótulos em \(\{0, 1\}\), o erro \(y - \hat y\) vale 0 num acerto (nenhuma atualização), \(+1\) num falso negativo (soma \(\eta\mathbf{x}\) e aumenta \(b\)) e \(-1\) num falso positivo (subtrai \(\eta\mathbf{x}\) e diminui \(b\)). A forma \(\mathbf{w} \leftarrow \mathbf{w} + \eta\,y\,\mathbf{x}\) é da convenção \(\pm 1\); com \(y = 0\) ela nunca corrigiria um falso positivo.
    • Inicialização: \(\mathbf{w}_0\) = rng.normal(0, 0.01, size=2) = \((0.009914,\ -0.008270)\) e \(b_0 = 0\). O vetor é sorteado fora da classe e passado a ela, para que a execução com \(\eta = 1.0\) parta do mesmo ponto.
    • Taxa de aprendizado: \(\eta = 0.01\).
    • Parada: uma época inteira sem nenhuma atualização, ou 100 épocas. A acurácia na base inteira é registrada ao fim de cada época.

    Acurácia dos pesos iniciais 61.50%

    D — Análise¶

    Por que converge rápido. A regra só age quando erra: num acerto, \(y - \hat y = 0\) e os pesos não mudam. Cada erro empurra a fronteira na direção que corrige aquele ponto. Como as nuvens estão a ~7 desvios-padrão uma da outra, existe um vão largo onde qualquer reta acerta tudo. Assim que a fronteira cai nesse vão, todo ponto passa a ser acerto, e não há mais o que atualizar. O número de atualizações por época foi 48 → 0 (\(\eta = 0.01\)) e 25 → 0 (\(\eta = 1.0\)). A última atualização aconteceu na amostra 1457 de 2000 da primeira época; as 543 amostras seguintes e a época 2 inteira passaram sem erro. O teorema de convergência dá um teto para isso (item 2D): com a reta de margem máxima destes dados (\(\gamma = 0.235\), achada por varredura) e \(\lVert\mathbf{x}\rVert \le R = 9.12\), o limite é de 32 898 erros. É um limite folgado, mas finito; na prática foram 25 a 48. A Figura 3(b) mostra que, antes de cair no vão, uma atualização isolada às vezes derruba a acurácia de 99% para 50%. É o mesmo efeito que, no Exercício 2, não para nunca.

    Reexecução com \(\eta = 1.0\) (mesmos dados, ordem e \(\mathbf{w}_0\)):

    \(\eta = 0.01\) \(\eta = 1.0\)
    Épocas 2 2
    Atualizações 48 25
    Acurácia final 100.00% 100.00%
    \(\mathbf{w}\), \(b\) \((0.031891,\ 0.028736)\), \(-0.20\) \((1.717344,\ 1.664585)\), \(-11.0\)
    Direção \(\mathbf{w}/\lVert\mathbf{w}\rVert\) \((0.7429,\ 0.6694)\) \((0.7181,\ 0.6960)\)
    Distância da fronteira à origem 4.659 4.599

    As duas chegam a 100%, mas por fronteiras diferentes: as direções diferem em 2.09° (Figura C1). O que \(\eta\) controla fica claro desenrolando a regra. Depois de \(t\) atualizações com erros \(e_s\):

    \[ \begin{aligned} \mathbf{w}_t &= \mathbf{w}_0 + \eta\sum_{s<t} e_s\,\mathbf{x}_s, & b_t &= \eta\sum_{s<t} e_s \\ \Longrightarrow\quad \frac{\mathbf{w}_t}{\eta} &= \frac{\mathbf{w}_0}{\eta} + \sum_{s<t} e_s\,\mathbf{x}_s, & \frac{b_t}{\eta} &= \sum_{s<t} e_s . \end{aligned} \]

    A predição \(\text{step}(\mathbf{w}\cdot\mathbf{x} + b)\) não muda se \((\mathbf{w}, b)\) for dividido por \(\eta > 0\). Logo, treinar com \(\eta\) a partir de \(\mathbf{w}_0\) é exatamente o mesmo que treinar com \(\eta = 1\) a partir de \(\mathbf{w}_0/\eta\). O \(\eta\) não regula o "tamanho do passo" da fronteira: regula o peso da inicialização aleatória frente às atualizações.

    • Com \(\eta = 0.01\), a partida efetiva é \(\mathbf{w}_0/\eta = (0.99,\ -0.83)\), de norma 1.29, comparável a uma amostra (\(\overline{\lVert\mathbf{x}\rVert} = 4.65\)) e apontando para \((+, -)\). As primeiras atualizações gastam esforço desfazendo essa orientação (48 em vez de 25), e a direção final guarda um resquício dela: ficou girada para o lado de \(x_1\).
    • Com \(\eta = 1.0\), a partida efetiva é o próprio \(\mathbf{w}_0\), de norma 0.013, desprezível diante de \(\lVert\mathbf{x}\rVert \approx 4.65\). A execução praticamente coincide com a partida do zero: as mesmas 25 atualizações, o mesmo \(b = -11\) e uma direção a só 0.31° dela.

    Partindo de \(\mathbf{w} = \mathbf{0}\), \(b = 0\), \(\eta\) não tem efeito nenhum. Sejam \((\mathbf{w}_t, b_t)\) os pesos depois de \(t\) amostras com \(\eta_1\) e \((\mathbf{w}'_t, b'_t)\) com \(\eta_2\), os dois a partir de \((\mathbf{0}, 0)\) e com a mesma sequência de amostras. Seja \(c = \eta_2/\eta_1 > 0\). Afirmo que \((\mathbf{w}'_t, b'_t) = c\,(\mathbf{w}_t, b_t)\) para todo \(t\). Por indução:

    • Base (\(t = 0\)): \((\mathbf{0}, 0) = c\,(\mathbf{0}, 0)\).
    • Passo. Suponha que vale em \(t\) e seja \(\mathbf{x}\) a próxima amostra. A entrada líquida é \(z'_t = \mathbf{w}'_t\cdot\mathbf{x} + b'_t = c\,(\mathbf{w}_t\cdot\mathbf{x} + b_t) = c\,z_t\). Como \(c > 0\), \(z'_t \ge 0 \iff z_t \ge 0\), então \(\hat y'_t = \hat y_t\) e o erro é o mesmo, \(e'_t = e_t\). Portanto \(\mathbf{w}'_{t+1} = c\,\mathbf{w}_t + \eta_2 e_t\mathbf{x} = c\,(\mathbf{w}_t + \eta_1 e_t\mathbf{x}) = c\,\mathbf{w}_{t+1}\) e, do mesmo modo, \(b'_{t+1} = c\,b_t + \eta_2 e_t = c\,b_{t+1}\). \(\blacksquare\)

    Consequências: as duas execuções fazem as mesmas predições em todo passo, logo as mesmas atualizações e a mesma época sem erro, ou seja, o mesmo número de épocas. A fronteira \(\{\mathbf{x} : c(\mathbf{w}\cdot\mathbf{x} + b) = 0\}\) é a mesma reta. Na fórmula desenrolada acima isso é imediato: com \(\mathbf{w}_0 = \mathbf{0}\), a partida efetiva \(\mathbf{w}_0/\eta\) é zero para todo \(\eta\). Conferi numericamente: partindo do zero, \(\eta = 0.01\) e \(\eta = 1\) fazem as mesmas 25 atualizações em 2 épocas, com \(\mathbf{w}' / \mathbf{w} = (100.000,\ 100.000)\) e \(b'/b = 100.000\) (\(b = -0.11\) contra \(-11\)). É por isso que o item B proíbe a partida do zero: o experimento com \(\eta\) não teria o que medir.

def best_line_accuracy(X, y, n_angles=1440):
    """Melhor acurácia com UMA reta: varre direções e todos os limiares (w·x >= t -> classe 1)."""
    best = 0.0
    for theta in np.linspace(0, 2 * np.pi, n_angles, endpoint=False):
        s = X @ np.array([np.cos(theta), np.sin(theta)])
        ys = y[np.argsort(s)]
        ones_right = np.concatenate([[ys.sum()], ys.sum() - np.cumsum(ys)])
        zeros_left = np.concatenate([[0], np.cumsum(1 - ys)])
        best = max(best, float(((ones_right + zeros_left) / len(y)).max()))
    return best


def signed_distance(w, b, point):
    """Distância com sinal do ponto à reta w·x + b = 0 (positivo = lado da classe 1)."""
    return float((w @ point + b) / np.linalg.norm(w))


def describe(w, b, X, y):
    w = np.asarray(w)
    pred = (X @ w + b >= 0).astype(int)
    return {
        "w": w.tolist(), "b": float(b), "accuracy": float(np.mean(pred == y)),
        "norm_w": float(np.linalg.norm(w)),
        "distance_origin_to_boundary": float(abs(b) / np.linalg.norm(w)),
        "signed_distance_center_to_boundary": signed_distance(w, b, CENTER),
        "fraction_predicted_class1": float(pred.mean()),
    }

        "mean_updates_per_epoch": float(h["updates"].mean()),
        "pocket_accuracy": m.pocket["accuracy"],
    }

    D — Análise¶

    A diferença entre os pesos finais e o bolso. A fronteira do bolso corta a nuvem pelo meio: passa a 0.04 do centro \((3.5,\ 3.5)\), a 4.99 da origem, e prevê classe 1 para 47.8% dos pontos. A fronteira final passa 0.98 abaixo do centro, a 3.89 da origem. Ela prevê classe 1 para 75.75% dos pontos e erra 609 dos 1000 da classe 0 (Figura 5b). Mas o laço não "deixou" a fronteira ali: ela estava só passando. Na última época, a distância do centro à fronteira variou de 1.8 de um lado a quase 9 do outro (percentis 5% e 95%). Em 55% das atualizações, o centro ficou a mais de 1 desvio-padrão da reta. Ao longo das 100 épocas, a acurácia logo após cada atualização teve mediana de 60.8%, e 11% das atualizações a deixaram em 50% ou menos (Figura 6). Os pesos finais são uma foto tirada no meio dessa oscilação.

    Por que oscila: \(b\) anda pouco e \(\mathbf{w}\) anda muito. A cada erro, \(b\) muda \(\eta = 0.01\), e \(\mathbf{w}\) muda \(\eta\,\mathbf{x}\), cujo tamanho médio é \(0.01 \times 5.11 = 0.051\). A fronteira fica a \(|b|/\lVert\mathbf{w}\rVert\) da origem. Para cortar a nuvem, que está a ~4.95 da origem, é preciso \(\lVert\mathbf{w}\rVert \approx |b|/4.95\). Como \(|b|\) ficou preso perto de 0.45 (entre 0.40 e 0.48 na última época), \(\lVert\mathbf{w}\rVert\) precisa valer ~0.09. Um único passo, 0.051, é mais da metade disso.

    • Num falso negativo, \(\mathbf{w}\) ganha ~0.05 na direção da diagonal, \(\lVert\mathbf{w}\rVert\) vai de ~0.09 a ~0.14 e a fronteira salta de ~5.0 para ~3.2 da origem. É um salto de ~1.8, maior que o desvio-padrão da nuvem (1.22).
    • Num falso positivo acontece o contrário: \(\lVert\mathbf{w}\rVert\) pode cair quase a zero (chegou a 0.008), e a fronteira é jogada para \(0.45/0.008 \approx 56\) da origem, longe da nuvem inteira. Tudo vira classe 0, e a acurácia vai a 50%.

    E \(|b|\) não cresce para tornar os passos relativamente pequenos: ele sobe 0.01 a cada falso negativo e desce 0.01 a cada falso positivo. Com as classes sobrepostas, os dois tipos de erro continuam chegando em proporções parecidas, então \(b\) só vagueia (Figura C2a). A escala de \(\mathbf{w}\) fica presa à de um único passo, e a reta nunca se acomoda.

    Mais uma evidência: a ordem das amostras. Com as classes em bloco (os 1000 pontos da classe 0, depois os 1000 da classe 1; mesmos dados, mesmo \(\mathbf{w}_0\)), a oscilação vira uma alternância. Na última época houve só 4 atualizações. Dois erros, nas amostras 1 e 4 do bloco da classe 0, bastaram para jogar a reta para longe: ao fim desse bloco, o modelo previa classe 0 para 100% dos pontos. Outros dois, nas amostras 1 e 49 do bloco da classe 1, levaram a reta para o outro extremo ("tudo classe 1"). Toda época termina no bloco da classe 1, então os pesos finais preveem classe 1 para 99.75% dos pontos e acertam 50.25%, o número que o enunciado antecipa. O bolso, nesse caso, fica em 69.25%.

    Figura 3 × Figura 6: o que o teorema garante. O teorema de convergência do perceptron (Novikoff, 1962) diz o seguinte. Se existe uma reta que separa as classes com margem \(\gamma > 0\) e todo ponto (aumentado com 1 para o viés) tem norma \(\le R\), então o perceptron faz no máximo \((R/\gamma)^2\) erros e para, com 100% de acurácia no treino. Partindo do zero, com o viés incluído, isso vale \((R^2+1)(1+b^{*2})/\gamma^2\). No Exercício 1 a hipótese vale (\(\gamma = 0.235\)), e a curva da Figura 3 se acomoda em 100% depois de 25 a 48 erros. Aqui a hipótese quebrada é a separabilidade linear: não existe \(\gamma > 0\), porque a melhor reta ainda erra 29.25% dos pontos. Sem margem, o teorema não dá limite nenhum, e o laço faz ~765 atualizações em toda época, sem tendência de queda (Figura 6). Os pesos continuam limitados (\(\lVert\mathbf{w}\rVert \le 0.18\) na última época), mas ficam ciclando em vez de convergir.

    Mais épocas resolvem? Não. A regra atualiza toda vez que erra, e qualquer reta erra pelo menos 585 dos 2000 pontos. Então toda época, por mais tardia, traz centenas de atualizações, cada uma do tamanho de meio \(\lVert\mathbf{w}\rVert\). Nada na regra diminui com o tempo, e ela não guarda memória de quais pesos foram bons: o processo da época 1000 é estatisticamente o mesmo da época 100.

    Um \(\eta\) menor resolve? Também não. Pela identidade do item 1D, \(\mathbf{w}_t/\eta = \mathbf{w}_0/\eta + \sum_s e_s\mathbf{x}_s\) e \(b_t/\eta = \sum_s e_s\). Diminuir \(\eta\) encolhe \(\mathbf{w}\), \(b\) e os passos na mesma proporção, então a razão passo / \(\lVert\mathbf{w}\rVert\), que é o que faz a reta saltar, não muda. Partindo do zero, a sequência de fronteiras seria idêntica para qualquer \(\eta\). Partindo de \(\mathbf{w}_0 \ne \mathbf{0}\), um \(\eta\) menor só aumenta o peso da inicialização aleatória nas primeiras atualizações.

    Rodei as duas variações só para confirmar, mesmos dados e mesmo \(\mathbf{w}_0\):

    Variação Acurácia final Faixa nas últimas 50 épocas Atualizações por época Bolso
    \(\eta = 0.01\), 100 épocas (principal) 64.85% 61.45%–68.30% 766 70.70%
    \(\eta = 0.01\), 1000 épocas 65.05% 54.55%–66.90% 766 70.75%
    \(\eta = 0.001\), 100 épocas 68.25% 62.80%–68.25% 766.5 70.70%

    Em todas as variações a oscilação continua, e só o bolso entrega ~70.7%. O que resolveria seria mudar o algoritmo, não os hiperparâmetros: guardar o melhor (o bolso), fazer a média dos pesos ao longo do treino (averaged perceptron), usar uma taxa que decai com o tempo, ou trocar a regra por uma perda que tem mínimo, como a regressão logística.
